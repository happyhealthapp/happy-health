# Happy Health

Home care medical services platform — connecting patients in Pakistan to qualified nursing staff, doctor home visits, and rentable medical equipment, delivered at home.

Built as part of the **SEIC (Sindh Enterprise Incubation Center) 6-month founder incubation program** (sessions Mon/Wed/Fri from 25 Sep 2026).

## For mentors — start here

👉 **[`assignments/`](assignments/)** — every session's notes, assignment, and submission in date order. Each folder has its own README.

| Path | Purpose |

## Project at a glance

- **What**: On-demand home care — home nursing, doctor home visits, medical equipment rental
- **Who**: Patients & families in Pakistan; verified nurses & doctors; equipment renters
- **Stack**: React + Vite + TypeScript + Supabase (web-first)
- **Status**: 🚧 Inception — assignments in progress, platform in planning
