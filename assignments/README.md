## How this folder works

- One folder per session, named `YYYY-MM-DD-topic/`
- Each session folder contains:
  - `README.md` — session notes, learning objectives, resources
  - `assignment.md` — the task, my submission, and reflection
- Copy [`_template/`](_template/) to start a new session folder
